# Why this file exists

`dream-dynamics.md` maintained its bibliography by hand as a numbered list until
2026-08-24, when the manuscript moved to `[@citekey]` markers with the list generated by
pandoc from `references.bib`. The hand-curated list is kept here rather than deleted, for
three reasons:

1. It is the object `scripts/build_references_bib.py` verifies Crossref records against —
   first author, year and title overlap. Delete it and the bibliography stops being
   machine-checkable against anything.
2. It records presentation decisions (short titles, the imprint an edition was cited from,
   which of two editions a page range came from) that Crossref does not carry.
3. Entries 1–49 are the numbering that external reviews of this manuscript refer to. Two
   reviews in `00-inbox/` cite reference numbers; without this file those pointers dangle.

Entries 1–49 are verbatim as printed in the manuscript on 2026-08-24. Entries 50 onward
were added after the numbered list was retired and never carried a printed number in the
manuscript; they are written in the same format so the verifier treats them identically.

Six of these numbers (5, 17, 18, 22, 25, 38) bundle two distinct works, which is why 49
numbers resolve to 54 works in the seed. Number 36 is a prose note about data providers,
not a citable work; it now lives in the manuscript's data-availability section.
